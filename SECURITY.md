# Security Policy

CipherGuard-AegisFusion is intended for defensive security research, teaching, and authorized traffic analysis.

## Responsible Use

- Use the project only on systems, networks, PCAPs, and datasets you are authorized to inspect.
- Do not use controlled attack-lab components against third-party systems without explicit permission.
- Do not commit credentials, private keys, tokens, internal IP addresses, or personal information.

## Reporting Security Issues

If you discover a vulnerability in the project itself, avoid publishing working exploitation details in a public issue before a fix is available. Prefer a private disclosure channel when one is configured for the repository.

## Dataset and Model Files

Datasets, raw PCAP files, large model weights, local service state, and environment secrets are intentionally excluded from the ordinary Git history. Reproduction instructions should reference official dataset sources or separately distributed release artifacts.
